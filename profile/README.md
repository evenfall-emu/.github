Evenfall is a project of building modern open-source emulators for classic consoles. Each one is written
from scratch, test-first, against published hardware documentation and test
ROMs, around a deterministic core that runs natively and in the browser.

Determinism at a very performance allows all sorts of fun integrations like multiplayer experiences, infinite state rewind and reinforcement learning gym. 

### Evenfall.org

Evenfall first emulator was built as an experiment on making the best possible experience for players to enhance their gameplay with integrated HUD, extreme efficiency for low-end devices and portability.
In this effort, we've built a platform to play online on any romhack you can load on a real GBA, with QoL features left-and-right like cloud saves, infinite state rewind, branching, handling multiple playthroughs, etc.
Don't hesitate to raise bugs, issues or product feedback, this is something for the community and I hope this makes it easier to casual players to try new experiences based on the old classics.

You can [play in the browser](https://play.evenfall-emu.org) if you ever need to launch a GBA game.
