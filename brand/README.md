# Evenfall brand kit

The Evenfall mark is a pixel sun setting behind a hill, above two bands of
sea. It is drawn on a 32 × 32 grid; scale it by whole multiples where possible
and keep edges sharp (`image-rendering: pixelated`). The wordmark is set in
lowercase: `evenfall`.

| File | Use |
|---|---|
| [`svg/evenfall-icon.svg`](svg/evenfall-icon.svg), `png/evenfall-icon-{32…1024}.png` | the mark alone, transparent |
| [`svg/evenfall-logo.svg`](svg/evenfall-logo.svg), [`png/evenfall-logo.png`](png/evenfall-logo.png) | the mark with the wordmark, transparent, for dark backgrounds |
| [`svg/evenfall-wordmark.svg`](svg/evenfall-wordmark.svg), [`png/evenfall-wordmark.png`](png/evenfall-wordmark.png) | the wordmark alone, for dark backgrounds |
| [`evenfall-avatar.svg`](evenfall-avatar.svg), [`evenfall-avatar-500.png`](evenfall-avatar-500.png), [`evenfall-avatar-1000.png`](evenfall-avatar-1000.png) | the mark on night blue, square: profile avatars and app icons |
| [`png/evenfall-banner.png`](png/evenfall-banner.png) | the coast-at-dusk banner with the logo |

## Colors

| Role | Color |
|---|---|
| Night blue (background) | `#032F5A` |
| Sun | `#F5AA82` |
| Sea bands | `#8CDBBE` |
| Wordmark | `#FFF0C8` |

The wordmark is cream, so the logo and wordmark need a background as dark as
night blue. On light backgrounds use the mark alone or the avatar.

The Evenfall name and logo identify the Evenfall projects. Forks and derived
products must use a different name and logo.
