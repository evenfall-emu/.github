# Evenfall brand assets

The Evenfall mark is a pixel sun setting behind a hill, above two bands of
sea. It sits on a grid of 28 × 23 square units: scale it by whole multiples
where possible and keep edges sharp (`image-rendering: pixelated`).

| File | Use |
|---|---|
| [`evenfall-mark.svg`](evenfall-mark.svg) | the mark alone, transparent, any size |
| [`evenfall-logo.svg`](evenfall-logo.svg), [`evenfall-logo-500.png`](evenfall-logo-500.png), [`evenfall-logo-1000.png`](evenfall-logo-1000.png) | the mark on night blue, square: avatars and app icons |
| [`evenfall-lockup.png`](evenfall-lockup.png) | the mark with the `evenfall` wordmark, on night blue |
| [`evenfall-banner.png`](evenfall-banner.png) | the coast-at-dusk banner with the lockup |

## Colors

| Role | Color |
|---|---|
| Night blue (background) | `#032f5a` |
| Sun | `#fd9f70` |
| Sea bands | `#7ee0b9` |
| Wordmark | `#fcefce` |

The wordmark is set in lowercase. Keep the lockup on night blue or on a scene
dark enough for the cream wordmark to read.

The Evenfall name and logo identify the Evenfall projects. Forks and derived
products must use a different name and logo.
