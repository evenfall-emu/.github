# Evenfall brand assets

The Evenfall mark is a pixel-art sunset: a striped sun sets into a calm sea
under the evening star. It is drawn on a 32 × 32 pixel grid, so scale it by
whole multiples and keep pixels sharp (`image-rendering: pixelated`).

| File | Use |
|---|---|
| [`evenfall-logo.svg`](evenfall-logo.svg) | the mark, vector, any size |
| [`evenfall-logo-512.png`](evenfall-logo-512.png), [`evenfall-logo-1024.png`](evenfall-logo-1024.png) | avatars and social images |
| [`evenfall-banner.svg`](evenfall-banner.svg), [`evenfall-banner.png`](evenfall-banner.png) | wide header with the wordmark (1280 × 320) |

## Palette

| Role | Color |
|---|---|
| Night sky | `#0b2350` |
| Dusk | `#3d3174`, `#723e75` |
| Horizon | `#c9506a`, `#f46a55` |
| Sun | `#fee6a8`, `#fdd987`, `#fcc070`, `#f9a35e` |
| Sun glow and shadow | `#f0766a`, `#f45754` |
| Sea | `#11446c`, `#0a3358`, `#002240` |
| Waves | `#38a7a1`, `#027e8c` |
| Evening star | `#c2f8fc` |

The wordmark's small lettering uses the public-domain Misc-Fixed 5 × 7 font.

The Evenfall name and logo identify the Evenfall projects. Forks and derived
products must use a different name and logo.
